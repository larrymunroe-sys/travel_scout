# Record Stores (Used & New) Scout Skill

Discovers independent vinyl record stores, deep crate digging vaults, audiophile pressing shops, and neighborhood record hubs in your destination city.

## Execution
```bash
python .agents/skills/vinyl-record-scout/scripts/scout_vinyl.py

# Or target specific city:
python .agents/skills/vinyl-record-scout/scripts/scout_vinyl.py --city "San Diego"
```
