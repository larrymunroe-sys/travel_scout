# Craft Cocktail Bars & Speakeasies Scout Skill

Discovers hidden speakeasies (secret doors, bookshelf entries, phone booth passageways), intimate natural wine bars, artisanal mixology lounges, and historic cocktail institutions in your destination city.

## Execution
```bash
python .agents/skills/speakeasy-cocktail-scout/scripts/scout_speakeasy.py

# Or target specific city:
python .agents/skills/speakeasy-cocktail-scout/scripts/scout_speakeasy.py --city "San Diego"
```
