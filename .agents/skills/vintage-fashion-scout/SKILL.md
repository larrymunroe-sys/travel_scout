# Vintage Clothing Stores Scout Skill

Discovers curated vintage boutiques, retro apparel stores, vintage denim vaults, and archival fashion purveyors in your destination city.

## Execution
```bash
python .agents/skills/vintage-fashion-scout/scripts/scout_fashion.py

# Or target specific city:
python .agents/skills/vintage-fashion-scout/scripts/scout_fashion.py --city "San Diego"
```
