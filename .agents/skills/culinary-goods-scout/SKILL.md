# Cooking & Food-Related Stores Scout Skill

Discovers specialty culinary purveyors, professional cookware stores, handcrafted Japanese knife makers, spice markets, and gourmet pantry provisions in your destination city.

## Execution
```bash
python .agents/skills/culinary-goods-scout/scripts/scout_culinary_goods.py

# Or target specific city:
python .agents/skills/culinary-goods-scout/scripts/scout_culinary_goods.py --city "San Diego"
```
