# Vintage Music Instruments Scout Skill

Discovers iconic vintage guitar vaults, independent musical instrument stores, rare tube amp workshops, and boutique synthesizer shops in your destination city.

## Execution
```bash
python .agents/skills/vintage-gear-scout/scripts/scout_gear.py

# Or target specific city:
python .agents/skills/vintage-gear-scout/scripts/scout_gear.py --city "San Diego"
```
