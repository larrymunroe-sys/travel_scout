# Vintage & Modern Home Design Scout Skill

Discovers mid-century modern furniture galleries, artisan ceramics studios, architectural antiques shops, and independent design showrooms in your destination city.

## Execution
```bash
python .agents/skills/home-design-scout/scripts/scout_design.py

# Or target specific city:
python .agents/skills/home-design-scout/scripts/scout_design.py --city "San Diego"
```
